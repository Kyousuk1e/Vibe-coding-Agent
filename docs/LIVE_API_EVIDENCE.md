## 首次失败与定向回归

第一次真实测试在“写周报并添加待办”步骤失败：模型直接回答“已添加”，trace 中没有 todo 调用。原断言正确拒绝了该结果。修订 `src/prompt.js`，明确多项请求必须分别完成、文字确认不能代替实际操作，并加入“周报+待办”的原生调用示例。

修订后额外在三个独立 session 中使用下列真实输入验证，全部同时满足“todo调用成功 + 单条任务正确持久化”：

1. 本周完成了 Agent 工具注册，下周准备补测试。帮我写一段简短周报，并添加一条文字恰好为“周五提交周报”的待办。
2. 帮我把“已经完成登录接口，明天调试联调问题”整理成两句周报，顺便记待办：明天联调。
3. 请先记录一条待办：整理测试报告。然后根据本周新增了登录测试和导出测试这两项事实写一段周报。

随后重新执行上面的完整验收，全部通过。模型自主决策具有不确定性，这份证据只证明这些实际输入通过，不承诺任意输入都不会漏调用。上下文压缩、网络故障、轮次上限等边界另由确定性测试覆盖。
